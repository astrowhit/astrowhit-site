Data Challenge

Effective Plotting and Presentations Workshop

This workshop was originally developed for the UMass Astronomy Department Fall 2020 Journal Club. Included in the 2-session workshop is a “Data Challenge,” where participants are asked to download a spreadsheet of the astrophysics arXiv submissions between March 15th and August 10th of 2019 and 2020 (i.e., before and during COVID-19). Using code released by Professor Megan Frederickson, the CSV file contains two gender columns counting the total number of men and women (albeit an imperfect process, gender is automatically assigned through an applied algorithm whenever first names are specified). The GitHub is well documented and easy to use, so modifications are possible.

Results from the Data Challenge can be found in the gallery below, as well as links to the presentations and data. A special shout out to Zhiyuan Ji, the winner of the 2020 Data Challenge! And honorable mention goes to Nat DeNigris, both submitting top entries that you can check out in our gallery.
